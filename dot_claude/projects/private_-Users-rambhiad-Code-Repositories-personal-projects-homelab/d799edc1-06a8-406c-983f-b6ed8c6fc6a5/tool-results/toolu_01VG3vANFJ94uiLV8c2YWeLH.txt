## Key Changes in 2025

### Redis No Longer Required (as of 2025.10)
With release 2025.10, authentik has migrated caching, the embedded outpost, and WebSocket to Postgres, fully removing the need for Redis.(no content)Since 2025.8, tasks were migrated to use Postgres.

### PostgreSQL Resource Impact
As a result of this change, it is expected that authentik will use roughly 50% more database connections to Postgres.

### Upgrade Instructions for 2025.10
To upgrade, use: `wget -O docker-compose.yml https://goauthentik.io/version/2025.10/docker-compose.yml docker compose up -d --remove-orphans`. The `--remove-orphans` flag removes the Redis container as it's no longer needed.(no content)Redis-related settings have also been removed and can be deleted from your configuration.

### PostgreSQL Version Requirements
The PostgreSQL chart has been updated to version 16.7.4. The PostgreSQL image is no longer pinned in authentik's default values and has been upgraded from version 15 to 17.(no content)As of 2024.6, authentik requires PostgreSQL version 14 or later.

### VPS/Hardware Requirements
For production deployment, the minimum requirements are: 4GB RAM, 2 vCPUs, and 40GB storage running Ubuntu 24.04 LTS.

### Docker Compose Prerequisites
Docker installed on your system (version 20.10.0 or higher recommended). Docker Compose installed (version 1.27.0 or higher recommended).

### Previous Setup (Pre-2025.10)
For versions before 2025.10, the Docker Compose setup included:
- PostgreSQL: Database to store all configuration data. Redis: Cache non-persistent data, such as session details.

### Production Recommendations
From this point on, we recommend using the bundled PostgreSQL dependency for demonstration and test purposes only. See our installation documentation for alternatives to run PostgreSQL in a production environment.(no content)Database Optimization: Consider implementing connection pooling with PgBouncer for high-traffic environments. Regular database maintenance and proper indexing are crucial for authentication performance.
